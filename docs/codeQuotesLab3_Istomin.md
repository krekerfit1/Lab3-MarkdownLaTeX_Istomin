# Блоки кода и цитаты

## Inline-код
Для проверки состояния репозитория используйте команду `git status`.

## Блок кода с подсветкой
```csharp
print('hello world')
```

## Блок кода без указания языка
```
Имя пользователя: Istomin
Лабораторная работа: №3
Статус: Выполнено
```

## Цитаты
> Это обычная цитата в Markdown.

> Это первого уроня цитата.
> > А это вложенная цитата второго уровня.
