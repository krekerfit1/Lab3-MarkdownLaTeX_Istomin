# Списки в Markdown

Списки помогают структурировать информацию, перечислять пункты и облегчать восприятие текста.

Markdown поддерживает два вида списков:

## Маркированные списки

Создаются с помощью символов: `*`, `-` или `+`.

* 1
* 2
* 3

## Нумерованные списки

Создаются с помощью цифр с точкой:

1. Первый пункт
2. Второй пункт
3. Третий пункт

## Вложенные списки

Просто используйте отступ (таб или 4 пробела):

1. Пункт
    - Подпункт
    - Подпункт
